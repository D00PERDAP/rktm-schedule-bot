# РКТМ: Telegram-бот + Mini App — единый профиль

## Что работает
- Бот и мини-приложение используют один FastAPI-сервер и одну SQLite-базу.
- Mini App подтверждает личность по подписанному Telegram `initData` (HMAC-SHA256, срок 24 часа).
- Выбранное расписание и настройка уведомлений сохраняются на сервере для того же Telegram ID.
- Команда `/group` и Mini App читают/изменяют одну запись.
- Изменения расписания проверяются фоновым монитором; сообщения отправляются подписчикам Telegram.
- Вне Telegram просмотр расписания доступен, синхронизация профиля недоступна.

## Запуск
1. `python -m venv venv` и активировать окружение.
2. `pip install -r requirements.txt`
3. Настроить `BOT_TOKEN`, `WEBHOOK_SECRET`, `WEBAPP_URL` (публичный HTTPS-адрес), `ADMIN_TOKEN` и `DATABASE_PATH` в окружении.
4. `uvicorn app:app --host 0.0.0.0 --port 8000` (для Render: `uvicorn app:app --host 0.0.0.0 --port $PORT`).
5. Открыть бота, отправить `/start`, нажать «Открыть расписание», выбрать группу, включить уведомления и сохранить.
6. Проверить `/health` и затем `/api/me` из Mini App.

## Ограничения
- Нужны настоящий Telegram-токен, HTTPS и проверка на сервере; здесь интеграционные проверки с Telegram не проводились.
- Для SQLite нужен постоянный диск; запускать один серверный worker, иначе фоновый монитор будет дублироваться.
- MAX пока не подключён: для него нужна отдельная проверка авторизации и API.
- ИИ-помощник и графическая админ-панель остаются отдельными этапами.
- Для публичного развёртывания необходимы rate limiting, резервное копирование и наблюдаемость.
