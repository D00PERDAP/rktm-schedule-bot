# Telegram-бот расписания РКТМ

Стартовый проект: Telegram-бот + Web App с адаптивным интерфейсом расписания.

## Что уже предусмотрено
- Telegram-бот с кнопкой открытия мини-приложения.
- Выбор источника расписания: основное / П / А.
- Поиск по тексту страницы расписания.
- Раздел замен с открытием актуального PDF.
- Серверный прокси для загрузки источников, чтобы браузер Web App не упирался в CORS.
- Настраиваемый URL замен через переменную `REPLACEMENTS_URL`.

## Важно про замены
Ссылка на PDF меняется по дате. Сейчас в `.env` задаётся конкретный URL. Для полностью автоматического поиска нового PDF нужен стабильный шаблон/страница сайта, где публикуется текущая ссылка. В проекте есть точка `get_replacements_url()` для такой логики; если URL-формат остаётся непредсказуемым, лучше получать ссылку со страницы расписания/новостей, а не угадывать имя файла.

## Запуск локально
Требуется Python 3.11+.

1. Создайте бота через `@BotFather`, скопируйте токен.
2. Скопируйте `.env.example` в `.env` и заполните `BOT_TOKEN`.
3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
4. Запустите сервер:
   ```bash
   uvicorn app:app --host 0.0.0.0 --port 8000
   ```
5. Во втором терминале:
   ```bash
   python bot.py
   ```
6. Для Telegram Web App нужен публичный HTTPS URL. Разместите проект на VPS/Render/Railway и укажите `WEBAPP_URL` в `.env`.

## Настройка BotFather
- `/setmenubutton` → выбрать бота → указать URL мини-приложения.
- URL должен быть HTTPS.
- Также бот отправляет кнопку «Открыть расписание» по `/start`.

## Источники
- `https://rktm.info/wp-content/uploads/HTML/raspisan.html`
- `https://rktm.info/wp-content/uploads/HTML/Praspisan.html`
- `https://rktm.info/wp-content/uploads/HTML/Araspisan.html`

Данные извлекаются как HTML-текст. Если исходные страницы содержат таблицы, сервер сохраняет структуру строк и ячеек; если формат на сайте изменится, может потребоваться поправить парсер.
