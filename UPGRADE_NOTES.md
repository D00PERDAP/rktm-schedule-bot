# РКТМ — модернизация, этап 1

## Реализовано в этой сборке
- Личное избранное расписание: выбор группы/преподавателя/аудитории сохраняется в localStorage на конкретном устройстве; есть быстрый переход и удаление.
- При открытии расписания приложение пытается выбрать текущий день недели (если день есть в данных).
- Серверный TTL-кеш HTML-страниц расписания (`CACHE_TTL_SECONDS`, по умолчанию 300 секунд). При сетевой ошибке отдаётся последняя успешно загруженная версия в памяти процесса.
- Webhook Telegram отклоняет запросы, если `WEBHOOK_SECRET` не задан; в production настройте секрет и Telegram webhook.
- Из выдаваемого архива исключены `.env`, `venv`, `.git`, логи и другие секреты.

## Ещё не реализовано
- Синхронизация профиля между устройствами (потребуется проверка Telegram initData и БД).
- Уведомления о заменах (потребуются нормализация расписания, история изменений, подписки и фоновая задача).
- Новости, админ-панель, ИИ и MAX API.
- Полный редизайн интерфейса и перенос JS-парсера на сервер.

## Запуск
1. `python -m venv .venv` и активируйте окружение.
2. `pip install -r requirements.txt`.
3. Создайте `.env` локально по примеру `.env.example`; **не публикуйте** его. Для запуска через uvicorn передайте переменные окружения в процесс (или загрузите их через dotenv).
4. `uvicorn app:app --host 0.0.0.0 --port 8000`.
5. Для Telegram задайте `BOT_TOKEN`, `WEBAPP_URL` (публичный HTTPS), `WEBHOOK_SECRET` (случайный секрет из A-Z, a-z, 0-9, _ и -).

Не запускайте `bot.py` одновременно с webhook-приложением, если он использует polling для того же бота.

## Важная безопасность
Исходный архив содержал `.env` и `.git`. Если токен бота когда-либо публиковался, перевыпустите его через BotFather. Эта сборка не включает исходные секреты.
