# РКТМ NEXT — Red Edition

Полностью обновлённый тёмно-красный интерфейс на базе существующего проекта. Telegram Mini App и бот используют один FastAPI и SQLite.

## Быстрый старт

1. Создайте виртуальное окружение: `python -m venv venv`
2. Активируйте его и выполните `pip install -r requirements.txt`
3. Скопируйте `.env.example` в `.env`, заполните `BOT_TOKEN`, `WEBAPP_URL`, `WEBHOOK_SECRET`, `ADMIN_TOKEN` (не публикуйте `.env`). При локальном запуске переменные должны быть загружены в окружение: `python-dotenv` установлен, но `app.py` не читает `.env` автоматически; используйте `set -a; source .env; set +a` в Linux либо настройте переменные в хостинге.
4. Запустите: `uvicorn app:app --host 0.0.0.0 --port 8000`
5. Для Telegram нужен публичный HTTPS `WEBAPP_URL`, совпадающий с адресом приложения. Запустите `/start` и откройте кнопку.
6. Проверка: `/health`, `/api/groups/raspisan`, `/api/news`.

## Реализовано

- Тёмный красный интерфейс NEXT, панель профиля, быстрые разделы, список расписаний, занятия по дням.
- Синхронизация выбранной группы и уведомлений между ботом и Mini App по проверенному Telegram initData.
- Новости и обращения через API; сообщения обратной связи отправляются из интерфейса.
- Команды `/start`, `/profile`, `/group`, `/mute`, `/news`, `/help`.
- Мониторинг изменений расписания (первое наблюдение не отправляет уведомление).

## Не выдавать за готовое

MAX и настоящий ИИ-ассистент **не подключены**. Администрирование новостей и обращений пока доступно через защищённые API, не через графическую панель. Для production нужны HTTPS, постоянное хранилище SQLite, один worker, резервные копии и ограничения частоты запросов. Запуск с реальным Telegram-токеном здесь не проверялся.
