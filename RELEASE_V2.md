# РКТМ v2 — внедрение и ограничения

## Реализовано в исходном коде
- Обновлённая главная страница и раздел новостей.
- Локальное избранное и просмотр расписания, включая преподавателей и аудитории.
- SQLite: подписки Telegram, новости, обращения, снимки расписания.
- Проверка изменений файлов по хешу и рассылка подписчикам (первый снимок не вызывает уведомления).
- Команды `/group <source> <filename.html>`, `/mute`, `/news`, `/help`.
- Защищённый ADMIN_TOKEN endpoint POST /api/admin/news и просмотр GET /api/admin/feedback.
- Слой общих сервисов, пригодный для будущего адаптера MAX.

## Ограничения / не считать готовым
- Полная интеграция MAX не реализована: нужен проверенный MAX Bot API, токен и регистрация webhook.
- ИИ-помощник не подключён: требуются согласованные документы колледжа и API провайдера.
- Админ-панель пока API, без отдельного графического интерфейса.
- Уведомления доступны через Telegram-команду, но не через кнопку Mini App без проверки Telegram initData.
- Мониторинг определяет изменение файла, а не конкретную отменённую пару; при каждом изменении файла уведомляет подписчиков.
- SQLite требует постоянного диска на хостинге; на эфемерном диске данные пропадут при перезапуске.
- Для публичного запуска нужны rate limiting, мониторинг ошибок, резервное копирование, проверка реальных HTML-файлов, нагрузочное тестирование.

## Запуск
1. Python 3.11+, `pip install -r requirements.txt`.
2. Скопировать `.env.example` в `.env`, заполнить переменные. Для локального запуска `python-dotenv` доступен, но окружение надо экспортировать самостоятельно, например `uvicorn app:app --env-file .env --host 0.0.0.0 --port 8000`.
3. Для Telegram использовать публичный HTTPS WEBAPP_URL и уникальный WEBHOOK_SECRET.
4. Запустить `uvicorn app:app --host 0.0.0.0 --port 8000`.
5. Админ публикует новость: `curl -X POST https://HOST/api/admin/news -H 'Content-Type: application/json' -H 'X-Admin-Token: SECRET' -d '{"title":"Объявление","body":"Текст"}'`.
6. В Telegram студент отправляет `/group raspisan example.html`, где example.html — реальное имя файла из `/api/groups/raspisan`.

**Безопасность:** если старый `.env` попал третьим лицам, перевыпустить токены. Никогда не публиковать ADMIN_TOKEN в клиентском JavaScript.
